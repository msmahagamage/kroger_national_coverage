# Processed data

Generated by `notebooks/01_prepare_locations.ipynb` or `scripts/build_all.py`:

- `kroger_official_locations.csv` — official Kroger API location records
- `state_summary.csv` — total and status counts by state
- `zip_summary.csv` — total and status counts by state and five-digit ZIP code
- `brand_summary.csv` — total and status counts by banner/brand

The location file includes `status` and `status_basis`. A record is classified
`active` when Kroger's official Locations API returned it on the collection
date in `api_collected_at_utc`. The public API does not provide closed-store
history or independent real-time operating confirmation.
