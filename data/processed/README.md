# Processed data

Generated by `notebooks/01_prepare_locations.ipynb` or `scripts/build_all.py`:

- `kroger_family_locations.csv` — one row per mapped supermarket
- `state_summary.csv` — total and status counts by state
- `zip_summary.csv` — total and status counts by state and five-digit ZIP code
- `brand_summary.csv` — total and status counts by banner/brand

The location file includes `status` and `status_basis`. Status reflects the
source's OpenStreetMap lifecycle tagging and is not a real-time Kroger check.
